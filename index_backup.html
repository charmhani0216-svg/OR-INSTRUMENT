학습 모드

두 가지 방법으로 수술기구를 학습합니다. 원하는 모드를 선택하세요.

판단하기

Doctor Mode

수술 진행상황을 보고 필요한 기구를 판단합니다.

핵심 학습

  1. 수술 흐름 이해
  2. 필요한 기구 판단
  3. 다음 기구 예측

현재 수술 단계와 상황을 읽고, 그 단계에서 필요한 기구를 선택지에서 고릅니다.

듣고 찾기

Scrub Mode

의사의 기구 요청을 듣고 올바른 기구를 선택합니다.

핵심 학습

  1. 기구명 듣기
  2. 기구 식별
  3. 정확한 기구 선택

예) "메첸바움 주세요." 음성을 듣고, 비슷한 기구들 중에서 정확한 기구를 고릅니다.

사용방법 · 도움말

어떤 순서로 학습하나요?

학습 모드(Doctor 또는 Scrub)를 고르고, 학습할 수술을 선택한 뒤 문제를 풉니다. 문제마다 정답/오답 피드백이 나오고 다음 문제로 넘어갑니다.

Doctor Mode와 Scrub Mode는 무엇이 다른가요?

Doctor Mode는 "지금 이 단계에서 어떤 기구가 필요할까?"를 스스로 판단하는 연습입니다. Scrub Mode는 의사가 부르는 기구 이름을 듣고 해당 기구를 빠르게 찾는 연습입니다.

Doctor Mode의 난이도는 어떻게 구성되나요?

기본: 기구 이미지를 보고 이름 고르기 → 중간: 수술 단계와 기구 이미지를 보고 이름 고르기 → 심화: 수술 상황만 보고 필요한 기구 이미지 고르기 순서로 구성될 예정입니다.

Scrub Mode의 음성은 어떤 발음인가요?

한국 수술실에서 실제로 사용하는 기구 호출 표현과 발음을 기준으로, 미리 제작·검토한 음성파일을 재생합니다. 모든 학습자가 같은 음성을 듣게 됩니다. 소리가 나오도록 스피커나 이어폰을 준비하세요.
